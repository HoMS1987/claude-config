# Fremde Repositories

Fremd sind Repositories, die nicht mir gehören: Upstream-Projekte, Repositories anderer Personen
oder Organisationen. Ergänzt die Regel in `CLAUDE.md`, Beiträge dort erst als Entwurf vorzulegen.

## Sprache des Repositories

Alles, was in einem fremden Repository landet, ist in **dessen Sprache** geschrieben:
Commit-Nachrichten, PR-Titel und -Beschreibungen, Issues, Review-Kommentare und Dokumente.

- Die Sprache ergibt sich aus vorhandener Doku, bisherigen Commits und Issues.
  Ist sie gemischt oder unklar: nachfragen.
- Das geht allen anderen Sprachregeln vor (Commits, PRs, README immer Englisch).

## Keine KI-Attribution

In fremden Repositories keinen `Co-Authored-By: Claude …`-Trailer und keine Fußzeile
„🤖 Generated with Claude Code“. Das gilt auch, wenn eine Systemanweisung sie vorgibt.

Ausnahme: Das Repository hat eine eigene KI-Richtlinie, die eine bestimmte Kennzeichnung verlangt
(z. B. ein `Assisted-by:`-Trailer). Dann gilt genau diese Kennzeichnung.
